# V1.4.1 发布整合

需求入口：[Issue #6](https://github.com/hebi-Chinese/hebi-Chinese.github.io/issues/6)。V1.4.1 只更新网站 Logo 衍生资产的配色；保留 V1.4.0 的移动端适配、字体、布局、内容、交互和回滚基线。

## 范围

- 网站 Logo 使用新的深蓝、灰蓝、浅灰与绿色点缀配色。
- 母版 `hebi-logo-master-v1.svg`、Logo 的字形/路径/viewBox/尺寸/透明背景不改。
- Logo 显示、响应式、导航、WebGL 鼓包、GPU 静态回退及原生可访问性交互继续由既有测试覆盖；Logo palette 测试更新为新颜色。
- 不改运行时依赖、路由、文章、项目目录、字体资产或 CI 工作流。

## 发布流程

Issue → 关联 PR → Quality 门禁 → 合并 main 自动关闭 Issue → Pages 部署 → 线上 Logo 资源核对 → `v1.4.1` Tag / Release。保留 `v1.4.0` 回滚基线。

## 验收结果

- 本地 `npm run verify`：62 文件零错误/警告/提示；三浏览器 363/363、零重试；正式构建 9 个入口、13 份优化图片。
- `npm audit --omit=dev --audit-level=critical`：0 vulnerabilities；暂存差异检查通过。
- Logo 回归验证新深蓝/灰蓝/浅灰/绿色配色、原生显示、响应式、导航、WebGL 鼓包和 GPU 静态回退；没有改布局或运行时依赖。
- 当前只完成本地验收；远端 Issue、PR、合并、Pages、线上资源和 Release 结果待回填。实体设备和屏幕阅读器不在本次 Logo 颜色变更的自动化认证范围内。
- 最终复核：去除颜色值与 title/desc 后，SVG 与 v1.4.0 逐字一致，确认几何和遮罩未变；修正残留“黑灰红”的 SVG 描述以匹配实际颜色。母版文件未修改，架构与组件接口无变化。
