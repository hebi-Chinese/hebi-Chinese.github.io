## 架构与审核

页面仍只组装内容；BaseLayout 挂载唯一分区导航运行时。About 通过明确的 flow-origin/hold/next-sheet 几何属性读取交接位置。ProfileThread 持有本实例观察器、监听与帧，统一清理；Logo 渲染器仅公开 resize/draw/dispose。没有新增依赖或单实现插件抽象。

沿用已有 deep-module 边界：ProjectsWheel 三项 props（id、headingLevel、immersive）隐藏原生链接与拖动/惯性生命周期；其运动算法本次没有变化。Hero 既有装饰仍就近管理。新增 Logo 初始化回调与文档唯一导航 mount 的长函数例外有局部理由：具名短处理器共享生命周期状态，拆为传递状态的薄封装不改善边界；没有将交互逻辑放入页面。详见相应切片文档。
