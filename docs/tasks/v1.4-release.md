首轮 Linux run 35604257079 为 356/357。WebKit 快速键盘测试结束时活动卡片失焦，截图中项目标题持有焦点；01 状态断言曾瞬时通过，之后活动卡为 05。本地单项诊断性重复 8/8 通过，未用该结果绕过远端失败。用户已明确授权“修复并继续发布”。

先用 Playwright Clock 暂停初始绘制帧，在真实首页书签落点开始卡片键盘操作，再恢复帧，验证导航不得覆盖用户焦点。优先修正初始锚点导航与键盘输入竞争，不更改排版、卡片数据或运动效果；保留原快速切换断言，补充稳定回归后重跑完整门禁。资料：https://playwright.dev/docs/clock （时间是测试边界）；https://developer.mozilla.org/en-US/docs/Web/API/Element/keydown_event （键盘事件从实际焦点元素冒泡）。

已取得稳定红绿证据：新增 initial bookmark landing 测试在旧源码 WebKit 上失败于活动卡片失焦（5s），与 Linux trace 的标题抢焦点一致。原全局导航只将垂直方向等键视为用户中断，遗漏了卡片的左右方向键；用户已操作后，初始化双 rAF 仍聚焦分区标题。仅将 ArrowLeft/ArrowRight 加入现有中断键表，取消待执行聚焦并标记已交互。重建后新增回归三浏览器 3/3（5.7s）通过，没有改卡片状态机、布局、原断言、等待阈值或重试数。
