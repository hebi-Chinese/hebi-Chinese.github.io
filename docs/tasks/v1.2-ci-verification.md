## 结果

### 诊断结论

1. 测试报告缺失：隐藏目录 `.playwright/` 被 `upload-artifact` 默认排除。设置 `include-hidden-files: true`，仅上传这一目录，`if-no-files-found: warn`。Linux run 35508677060 已成功上传 44MB 诊断产物，API 返回 artifact 10604917744。
2. 开发服务器重载干扰：改为 `npm pretest` 先构建，Playwright 启动独占 4338 preview，使用 Astro 7 的 `ASTRO_PREVIEW_BACKGROUND=0`；`verify` 不再重复构建。Linux 正式产物验证中没有再出现 Chromium 首用例 navigation context destroyed。
3. 轮盘错误基线：本地正式产物 trace 显示 reduced-motion 释放后同步采样先读到旧位置，下一帧完成最后一次拖动绘制后所有后续坐标相同。采样器改为首个动画帧建立基线，再完整测量原时长，位移阈值不变。Linux run 35508677060 的全部惯性用例通过；没有修改轮盘运动参数或清空产品缓冲。
4. WebKit 交接采样：Linux 失败 JSON 仅含两个帧（61ms 与 977ms，均 opacity 0），而失败截图稍后已显示 AOAI。这种软件渲染/trace 下的低帧率无法保证 800ms 墙钟窗口捕捉 500ms 动画。改用 Playwright Clock 在真实页面和 native scroll 事件上逐帧推进，检查约 266ms 的中间透明度、底图持续不透明和 548ms 前完成。其他自然时间下的正反向滚动、键盘选择、空闲帧终止与 reduced-motion 测试保留。
5. 正式产物新增可访问性发现：`.wheel-hint` 的 `opacity:.6` 在静态 CSS 顺序下造成 2.34:1 对比度。删除该透明度和操作说明的淡入，保留字体、字号、文字色与内容。原首页/项目页三浏览器 axe 六项从失败变为 6/6 通过。
