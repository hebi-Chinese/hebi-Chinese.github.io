# V1.4.2 发布整合

需求入口：[Issue #8](https://github.com/hebi-Chinese/hebi-Chinese.github.io/issues/8)。本版更新浏览器标签页网站图标。

## 更新与接口

- 旧深底 H favicon 换为白底彩色网站 Logo，沿用现用 Logo 的路径、遮罩与深蓝/灰蓝/灰绿配色。
- 正常页面及旧地址跳转页的图标引用统一为 `/favicon.svg?v=2`，避免复用旧 URL 缓存。
- `package.json` 与 lockfile 更新为 1.4.2；原有 favicon 回归改为验证新引用和颜色。
- 无架构、组件接口、站点目录、路由、页面布局、客户端脚本或依赖变化。页面内 Logo 与品牌母版保持原样。

## 验收

- `npm run verify`：62 文件零错误/警告/提示；构建 9 个页面；Chromium / Firefox / WebKit 合计 363/363 通过，零重试，3.3 分钟。
- `npm audit --omit=dev --audit-level=critical`：0 vulnerabilities；`git diff --check` 通过。
- `xmllint --noout public/favicon.svg` 通过；嵌套 SVG 图形主体与现用网站 Logo 逐字一致；正式构建九个入口均使用同一新版引用。
- 正式预览九个路由 HTTP 200；favicon、页面 Logo、母版资源与源码字节一致，SVG MIME 正确。
- 浏览器中检查 16px / 32px / 128px 图标显示，无裁切。图标不改变页面响应式、键盘或动效逻辑，既有全套测试覆盖这些接口。
- 差异审查未发现新增 P0/P1/P2/P3 问题；不新增外部资源、依赖、权限或秘密信息。未声称完成实体设备/屏幕阅读器认证。

## 发布与回滚

Issue → 关联 PR → Quality → 合并 main 自动关闭 Issue → Pages → 线上图标及页面核验 → annotated tag / Release。远端实际结果记录于关联 PR 与 Release。

回滚基线 v1.4.1；如出现图标或页面回归，以新 revert 提交经相同门禁部署，不移动已有标签、不改写历史。
