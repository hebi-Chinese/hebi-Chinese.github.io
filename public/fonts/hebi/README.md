# Hebi 网页字体

已选字体：HannotateSC-W5（标题）及 HanziPenSC-W3（短批注）。用户已确认网页分发授权；这些文件不是开源字体，不授予第三方再分发许可。保留字体内部原始版权和名称元数据。

WOFF2 由 `scripts/package-webfonts.py` 生成，每款字体的实际常用字单独打包，其余中文按范围分包，由 `src/styles/webfonts.css` 按需加载。保留原实现所用中文 Unicode 范围内的全部源字体字符；范围外沿用西文/系统字体。新增文案无需重新打包：浏览器根据文字与 `unicode-range` 自动请求相应分包。只有源字体本身不支持的字仍需回退，不承诺全部 Unicode 汉字覆盖。

常用包按已构建页面的计算样式收集，不扫描源码注释，也不把正文黑体用字加入手写字体。本次生成标题 82 字、签名 2 字。普通内容更新照常 `npm run build` 并发布即可；下面的重新收集仅用于进一步优化新增标题/批注的下载量，不是显示正确性的前提。

## 可选的资源重新生成

1. `npm run build`。
2. 启动本地生产预览，例如 `npm run preview -- --host 127.0.0.1 --port 4357`。
3. 在另一个终端运行 `node scripts/collect-webfont-usage.mjs http://127.0.0.1:4357/`。它自动读取构建路由，在 375 / 768 / 1440 宽度按实际字体用途收集文字，更新 `scripts/webfont-usage.json`。重定向页不重复采集。不需要手写字表；动态内容和伪元素未采集到的字仍由完整分包覆盖。
4. 在含 `fonttools[woff]==4.60.2` 的 Python 环境运行 `python scripts/package-webfonts.py /path/Hannotate.ttc /path/Hanzipen.ttc`。也可用 `--usage /path/usage.json` 指定另一份用字清单。生成器完整重新生成，不再使用旧的 `--resume` 模式，避免跨输入复用过期分包。
5. 重新构建并运行 `npm test`，连同 CSS、用字清单和所有新字体文件一起提交/发布。结束预览服务。

资源文件名包含 WOFF2 内容的 SHA-256 前 16 位。内容变化时 URL 自动变化；相同源字体、清单和工具版本不会因为生成时间变化而刷新 URL。生成器不删除历史文件：已发布版本可能仍有旧页面引用它们。历史版本清理应与部署缓存保留策略一起安排，不要在新 CSS 发布前移除它引用的文件。

源 TTC 不入库。正常网站构建直接复制这些资产，不需要本机安装字体，也不需要字体转换工具。
